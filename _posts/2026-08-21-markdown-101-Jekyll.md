Markdown เป็นภาษาสำหรับจัดรูปแบบข้อความที่ใช้เขียนโพสต์ใน Blog ของ C2Z

ข้อดีคือเขียนง่าย อ่านง่าย และไม่จำเป็นต้องเขียน HTML ทั้งหมดด้วยตัวเอง

---

## ✏️ หัวข้อ

ใช้เครื่องหมาย `#` เพื่อสร้างหัวข้อ

    # หัวข้อใหญ่
    ## หัวข้อรอง
    ### หัวข้อย่อย
    #### หัวข้อย่อยระดับ 4

ตัวอย่าง:

## หัวข้อรอง

### หัวข้อย่อย

> **หมายเหตุ:** ไม่ต้องใส่ `# ชื่อบทความ` ซ้ำกับ `title:` ด้านบน เพราะ Jekyll จะแสดงชื่อบทความให้อัตโนมัติ

## 💻 Code ในข้อความ

    ให้เปิดไฟล์ `config.yml`

เหมาะสำหรับ:

- ชื่อไฟล์
- คำสั่ง
- ชื่อตัวแปร
- ชื่อโปรแกรม

## 💻 Code Block

ใช้เครื่องหมาย ``` คร่อมโค้ด

    ```html
    <h1>Hello C2Z</h1>
    <p>Hello World!</p>
    ```

สามารถระบุภาษาของโค้ดได้ เช่น:

    ```html
    <h1>C2Z</h1>
    ```

    ```css
    body {
        background: #111;
        color: #fff;
    }
    ```

    ```javascript
    console.log("Hello C2Z");
    ```

    ```powershell
    bundle exec jekyll serve
    ```

ภาษาที่ใช้บ่อย:

- `html`
- `css`
- `javascript`
- `js`
- `json`
- `powershell`
- `bash`
- `ruby`
- `yaml`
- `markdown`

    YYYY-MM-DD-title.md

## ⚙️ Front Matter

ทุกโพสต์ควรมี Front Matter อยู่ด้านบนสุดของไฟล์

ตัวอย่าง:

    ---
    layout: post
    title: "ชื่อบทความ"
    date: 2026-08-21 23:00:00 +0700
    categories: guide
    ---

### layout

กำหนด Layout ที่ใช้แสดงโพสต์

    layout: post

สำหรับ Blog ของ C2Z ให้ใช้ `post`

### title

กำหนดชื่อบทความ

    title: "ชื่อบทความ"

ชื่อนี้จะถูกนำไปแสดงเป็นหัวข้อใหญ่ของโพสต์โดยอัตโนมัติ

### date

กำหนดวันที่และเวลาของโพสต์

    date: 2026-08-21 23:00:00 +0700

รูปแบบ:

    YYYY-MM-DD HH:MM:SS +0700

### categories

กำหนดหมวดหมู่ของโพสต์

    categories: guide

สามารถใส่หลายหมวดหมู่ได้:

    categories: guide markdown jekyll

## 🧩 ตัวอย่างโพสต์แบบเต็ม

สร้างไฟล์:

    _posts/2026-08-22-test-post.md

แล้วใส่:

    ---
    layout: post
    title: "โพสต์ทดสอบ"
    date: 2026-08-22 20:00:00 +0700
    categories: test
    ---

    สวัสดีครับ 👋

    นี่คือโพสต์ทดสอบของ C2Z

    ## หัวข้อ

    นี่คือข้อความตัวอย่าง

    สามารถใส่ **ตัวหนา** และ *ตัวเอียง* ได้

    ### รายการ

    - รายการที่ 1
    - รายการที่ 2
    - รายการที่ 3

    ### คำสั่ง

    สามารถใช้คำสั่ง `jekyll serve` ได้

## 🚀 สร้างเว็บไซต์

หลังจากสร้างหรือแก้ไขโพสต์แล้ว ให้เปิด PowerShell ในโฟลเดอร์เว็บไซต์

ใช้คำสั่ง:

    bundle exec jekyll serve

จากนั้นเปิด:

    http://localhost:4000

เมื่อแก้ไขไฟล์ Markdown แล้ว Jekyll จะสร้างเว็บไซต์ใหม่ให้อัตโนมัติ

หากแก้ไขไฟล์ที่เกี่ยวข้องกับการตั้งค่าหรือ Layout อาจต้องหยุดเซิร์ฟเวอร์แล้วรันคำสั่งใหม่

## 📌 คำสั่งที่ใช้บ่อย

| สิ่งที่ต้องการ | Markdown |
| --- | --- |
| ตัวหนา | `**ข้อความ**` |
| ตัวเอียง | `*ข้อความ*` |
| ลิงก์ | `[ข้อความ](URL)` |
| รูปภาพ | `![ข้อความ](URL)` |
| หัวข้อ | `## หัวข้อ` |
| รายการ | `- รายการ` |
| รายการตัวเลข | `1. รายการ` |
| Code ในข้อความ | `` `code` `` |
| Code Block | ` ``` ` |
| Blockquote | `> ข้อความ` |
| เส้นแบ่ง | `---` |
| Checkbox | `- [ ]` |
| ตาราง | `| ตาราง |` |
