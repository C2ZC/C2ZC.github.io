ยินดีต้อนรับเข้าสู่การเขียนบล็อกด้วย **Jekyll** ครับ!

รู้หรือไม่ว่าการเขียนบทความลงเว็บนั้น เราไม่จำเป็นต้องเขียนโค้ดเว็บ (HTML) ยากๆ เลย เราสามารถใช้สิ่งที่เรียกว่า **Markdown** แทนได้ ซึ่งก็คือการพิมพ์ข้อความธรรมดา แล้วใส่ "สัญลักษณ์พิเศษ" นิดหน่อย (เช่น ดอกจัน หรือขีดกลาง) ระบบของ Jekyll ก็จะแปลงโฉมให้กลายเป็นหน้าเว็บที่สวยงามอัตโนมัติ

นี่คือคำสั่งพื้นฐานทั้งหมดที่คุณต้องรู้ในการเริ่มเขียนโพสต์แรกครับ!

---

## 1. การทำตัวหนา และ ตัวเอียง

หากต้องการเน้นคำไหนให้เด่นชัด ให้ใช้สัญลักษณ์ดอกจัน `*` คร่อมคำนั้นไว้

* **ตัวหนา:** ใช้ดอกจัน 2 ตัว `**ข้อความ**` ➔ **ข้อความ**
* *ตัวเอียง:* ใช้ดอกจัน 1 ตัว `*ข้อความ*` ➔ *ข้อความ*
* ~~ขีดฆ่าข้อความ:~~ ใช้ตัวหนอน 2 ตัว `~~ข้อความ~~` ➔ ~~ข้อความ~~

---

## 2. การสร้างหัวข้อ

เวลาขึ้นหัวข้อใหม่ ให้ใช้เครื่องหมายชาร์ป `#` นำหน้า (อย่าลืมเว้นวรรค 1 เคาะด้วยนะครับ) ยิ่งมี `#` เยอะ หัวข้อยิ่งมีขนาดเล็กลง

```text
## หัวข้อหลัก (แนะนำให้ใช้ ## เป็นหัวข้อเริ่มต้นของเนื้อหา)
### หัวข้อรองลงมา
#### หัวข้อย่อย
```

---

## 3. การทำเป็นข้อๆ (รายการ)

ถ้าอยากเขียนลิสต์รายการเพื่อให้อ่านง่าย ใช้ขีดกลาง `-` หรือตัวเลขได้เลย

**แบบจุด:**
```text
- กินข้าว
- อาบน้ำ
- นอน
```

**แบบมีหัวข้อย่อยซ้อนกัน:**
(กด Spacebar 2 ครั้งด้านหน้าเพื่อทำรายการย่อย)
```text
- รายการที่ 1
- รายการที่ 2
  - รายการย่อย
  - รายการย่อยอีกหนึ่งรายการ
- รายการที่ 3
```

**แบบตัวเลข:**
```text
1. ตื่นนอน
2. แปรงฟัน
3. ไปทำงาน
```

---

## 4. รายการสิ่งที่ต้องทำ (Checkboxes)

เหมาะสำหรับทำลิสต์รายการเช็คลิสต์ต่างๆ 
* ใช้ `- [ ]` สำหรับรายการที่ยังไม่เสร็จ (เว้นวรรคตรงกลาง)
* ใช้ `- [x]` สำหรับรายการที่ทำเสร็จแล้ว (ใส่ตัว x ตรงกลาง)

```text
- [ ] ซื้อกาแฟ
- [x] ตอบอีเมล
```

ผลลัพธ์:

- [ ] ยังไม่ได้ทำ
- [x] ทำเสร็จแล้ว

---

## 5. การใส่ลิงก์ และ รูปภาพ

**การใส่ลิงก์ (กดแล้วไปเว็บอื่น):**
ใช้สูตร `[ข้อความที่จะให้แสดง](ใส่ URL ตรงนี้)`
* ตัวอย่าง: `[ไปหน้าแรกของ C2Z](https://c2z.top)`
* ผลลัพธ์: [ไปหน้าแรกของ C2Z](https://c2z.top)

**การใส่รูปภาพ:**
คล้ายกับลิงก์เลยครับ แค่เติมเครื่องหมายตกใจ `!` ไว้ด้านหน้าสุด
* ตัวอย่าง: `![โลโก้ของเว็บ](/assets/images/avatar.png)`
* ผลลัพธ์: ![โลโก้ของเว็บ](/assets/images/avatar.png)

## 6. การสร้างตาราง (Tables)

ใช้เครื่องหมายขีดตั้ง `|` เพื่อแบ่งคอลัมน์ และขีดกลาง `-` เพื่อแบ่งส่วนหัวตาราง

```text
| หัวข้อ 1 | หัวข้อ 2 | หัวข้อ 3 |
| :--- | :---: | ---: |
| ชิดซ้าย | กึ่งกลาง | ชิดขวา |
| ข้อมูล A | ข้อมูล B | ข้อมูล C |
```

ผลลัพธ์:

| หัวข้อ 1 | หัวข้อ 2 | หัวข้อ 3 |
| :--- | :---: | ---: |
| ชิดซ้าย | กึ่งกลาง | ชิดขวา |
| ข้อมูล A | ข้อมูล B | ข้อมูล C |

การจัดตำแหน่ง:

- `:---` = ชิดซ้าย
- `:---:` = กึ่งกลาง
- `---:` = ชิดขวา

---

## 7. กล่องข้อความอ้างอิง (Blockquote)

อยากทำกล่องข้อความคำคม หมายเหตุ หรือประกาศเตือน ให้ใส่เครื่องหมายมากกว่า `>` นำหน้า

```text
> ประกาศ: คืนนี้เซิร์ฟเวอร์จะปิดปรับปรุงนะครับ
```
ผลลัพธ์:
> ประกาศ: คืนนี้เซิร์ฟเวอร์จะปิดปรับปรุงนะครับ

**หากต้องการเขียนอ้างอิงแบบหลายบรรทัด:**
ให้ใส่ `>` นำหน้าในทุกๆ บรรทัดแบบนี้ครับ

```text
> นี่คือข้อความบรรทัดแรก
>
> นี่คือข้อความบรรทัดที่สอง
```

## 8. การใส่ตัวอย่างโค้ด

หากทำเว็บบล็อกสายไอทีแล้วต้องแปะโค้ด ให้ใช้เครื่องหมาย ` ` ` (Backtick) ซึ่งอยู่ตรงปุ่มเปลี่ยนภาษา (~)

**โค้ดสั้นๆ บรรทัดเดียว:** ใช้คร่อมหัวท้าย
* พิมพ์ว่า: `ให้เปิดไฟล์ \`config.yml\``
* ผลลัพธ์: ให้เปิดไฟล์ `config.yml`

**โค้ดแบบยาวๆ หลายบรรทัด (Code Block):** 
ใช้ ` ` ` 3 ตัว ปิดหัว-ท้าย และสามารถระบุชื่อภาษาโปรแกรมต่อท้ายเพื่อให้โค้ดมีสีสัน (Syntax Highlighting) ได้ เช่น `html`, `css`, `javascript` หรือ `powershell`

ตัวอย่าง HTML:
````text
```html
<div class="site-header">
  <h1>Welcome to C2Z</h1>
</div>
```
````

ตัวอย่าง JavaScript:
````text
```javascript
console.log("ยินดีต้อนรับสู่ C2Z!");
```
````

## 🚀 วิธีดูผลลัพธ์ (พรีวิว) ก่อนโพสต์จริง

เมื่อคุณเขียนไฟล์เสร็จและกดเซฟ (Save) แล้ว ให้เปิดหน้าต่าง Terminal ขึ้นมา แล้วพิมพ์คำสั่งนี้เพื่อจำลองเซิร์ฟเวอร์:

```bash
bundle exec jekyll serve
```

จากนั้นเปิดเว็บบราวเซอร์ของคุณแล้วเข้าพิมพ์ URL ว่า `http://localhost:4000` คุณก็จะเห็นบทความที่คุณเพิ่งเขียนเสร็จแสดงผลอยู่บนเว็บแล้วครับ!
