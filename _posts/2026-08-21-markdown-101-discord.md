Discord รองรับ **Markdown** ซึ่งเป็นระบบจัดรูปแบบข้อความที่ช่วยให้เราทำข้อความให้โดดเด่นและอ่านง่ายขึ้น เพียงใส่สัญลักษณ์บางอย่างไว้ด้านหน้าและด้านหลังข้อความที่ต้องการจัดรูปแบบ

บทความนี้รวบรวมรูปแบบ Markdown ที่ Discord รองรับและใช้งานได้บ่อย พร้อมตัวอย่างสำหรับนำไปใช้จริงครับ

> อ้างอิงรูปแบบจากเอกสาร Discord: ข้อความมาร์กดาวน์ 101 (การจัดรูปแบบแชท: ตัวหนา ตัวเอียง ขีดเส้นใต้)  
> https://support.discord.com/hc/th/articles/210298617

## 📝 1. การจัดรูปแบบข้อความ

Discord รองรับการจัดรูปแบบข้อความพื้นฐานหลายรูปแบบ เช่น ตัวเอียง ตัวหนา ขีดเส้นใต้ และขีดทับ

| รูปแบบ | ไวยากรณ์ | ผลลัพธ์ | คืออะไร |
| :--- | :--- | :--- | :--- |
| ตัวเอียง | `*ข้อความ*` | *ข้อความ* | ทำให้ข้อความเอียง |
| ตัวเอียง | `_ข้อความ_` | *ข้อความ* | ทำให้ข้อความเอียง |
| ตัวหนา | `**ข้อความ**` | **ข้อความ** | ทำให้ข้อความหนา |
| ตัวเอียง + ตัวหนา | `***ข้อความ***` | ***ข้อความ*** | ทำให้ข้อความหนาและเอียง |
| ขีดเส้นใต้ | `__ข้อความ__` | <u>ข้อความ</u> | ขีดเส้นใต้ข้อความ |
| ขีดทับ | `~~ข้อความ~~` | ~~ข้อความ~~ | ขีดเส้นทับข้อความ |

### ตัวอย่างการใช้งาน

```text
*ข้อความตัวเอียง*

**ข้อความตัวหนา**

***ข้อความตัวหนาและตัวเอียง***

__ข้อความขีดเส้นใต้__

~~ข้อความขีดทับ~~
```

สามารถนำหลายรูปแบบมาผสมกันได้ เช่น:

```text
__**ข้อความขีดเส้นใต้และตัวหนา**__

__*ข้อความขีดเส้นใต้และตัวเอียง*__

__***ข้อความที่ใช้ทุกแบบ***__
```

## ✏️ 2. หัวข้อ (Headings)

สามารถสร้างหัวข้อใน Discord ได้ด้วยเครื่องหมาย `#`, `##` และ `###`

ต้องวางเครื่องหมายไว้ที่จุดเริ่มต้นของบรรทัด และต้องมี **ช่องว่าง 1 ช่อง** ระหว่างเครื่องหมายกับข้อความ

### Heading 1

```text
# หัวข้อขนาดใหญ่
```

### Heading 2

```text
## หัวข้อขนาดกลาง
```

### Heading 3

```text
### หัวข้อขนาดเล็ก
```

### ตัวอย่าง

```text
# ประกาศสำคัญ

## ตารางอัปเดตเซิร์ฟเวอร์

### รายละเอียด
```

### คืออะไร

ใช้แบ่งเนื้อหาออกเป็นส่วนต่าง ๆ ทำให้ข้อความยาว ๆ อ่านง่ายขึ้นและมีโครงสร้างชัดเจน

> **หมายเหตุ:** ต้องมีช่องว่างหลัง `#` เสมอ เช่น `# หัวข้อ` ไม่ใช่ `#หัวข้อ`

## 🪶 3. ข้อความย่อย (Subtext)

Discord รองรับ **Subtext** สำหรับแสดงข้อความรองหรือข้อความที่ต้องการให้มีความสำคัญน้อยกว่าข้อความหลัก

### ไวยากรณ์

```text
-# ข้อความย่อย
```

### ตัวอย่าง

```text
-# อัปเดตล่าสุดเมื่อวันนี้
```

### คืออะไร

เหมาะสำหรับข้อความประกอบ เช่น วันที่อัปเดต คำอธิบายเพิ่มเติม หรือรายละเอียดรองที่ไม่ต้องการให้เด่นเท่าข้อความหลัก

> **หมายเหตุ:** ต้องเขียน `-#` ไว้ที่จุดเริ่มต้นของบรรทัด และต้องมีช่องว่างหลัง `#`

---

## 🙈 4. สปอยล์ (Spoiler)

สามารถซ่อนข้อความเป็นสปอยล์ด้วยเครื่องหมาย `||` คร่อมข้อความ

### ไวยากรณ์

```text
||ข้อความที่ต้องการซ่อน||
```

### ตัวอย่าง

```text
ตอนจบของหนังคือ ||ตัวละครหลักสามารถเอาชีวิตรอดได้||
```

### คืออะไร

ข้อความที่อยู่ระหว่าง `||` จะถูกซ่อนไว้ และผู้ใช้อื่นสามารถคลิกเพื่อเปิดดูข้อความได้

เหมาะสำหรับ:

- สปอยล์หนัง
- สปอยล์เกม
- คำตอบ
- ข้อมูลที่ไม่ต้องการเปิดเผยทันที

> **หมายเหตุ:** Discord ระบุว่าสปอยล์เป็นการจัดรูปแบบข้อความอีกประเภทหนึ่ง และสปอยล์จะไม่ทำงานภายใน Code Block

## 🔗 5. ลิงก์ที่ถูกบังไว้ (Masked Links)

สามารถเปลี่ยนข้อความธรรมดาให้เป็นลิงก์ที่คลิกได้ โดยใส่ข้อความไว้ใน `[]` และ URL ไว้ใน `()`

### ไวยากรณ์

```text
[ข้อความ](URL)
```

### ตัวอย่าง

```text
[เว็บไซต์ C2Z](https://c2z.top)
```

### ผลลัพธ์

[เว็บไซต์ C2Z](https://c2z.top)

อีกตัวอย่าง:

```text
สามารถอ่านข้อมูลเพิ่มเติมได้ที่ [Discord](https://discord.com)
```

### คืออะไร

ช่วยให้สามารถใช้ข้อความที่อ่านง่ายแทนการแสดง URL ยาว ๆ โดยตรง

## 📋 6. รายการ (Lists)

Discord รองรับรายการแบบหัวข้อย่อย และสามารถเยื้องเพื่อสร้างรายการย่อยได้

> **หมายเหตุ:** ต้องมีช่องว่างระหว่างสัญลักษณ์รายการกับข้อความ

### รายการแบบหัวข้อย่อย

ใช้ `-` หรือ `*` ที่จุดเริ่มต้นของแต่ละบรรทัด

```text
- รายการที่ 1
- รายการที่ 2
- รายการที่ 3
```

หรือ:

```text
* รายการที่ 1
* รายการที่ 2
* รายการที่ 3
```

### ตัวอย่าง

```text
- CPU
- GPU
- RAM
```

### รายการย่อย

เพิ่มช่องว่างด้านหน้ารายการ 2 ช่อง

```text
- คอมพิวเตอร์
  - CPU
  - GPU
  - RAM
- โทรศัพท์
  - Android
  - iOS
```

### คืออะไร

เหมาะสำหรับการจัดข้อมูลเป็นรายการ เช่น รายการอุปกรณ์ รายการคุณสมบัติ หรือขั้นตอนย่อยต่าง ๆ

## 💻 7. บล็อกโค้ด (Code Block)

สามารถสร้าง Code Block ได้โดยใช้ Backtick (`) คร่อมข้อความ

### โค้ดบรรทัดเดียว

ใช้ Backtick 1 ตัวที่ด้านหน้าและด้านหลังข้อความ

```text
`Hello Discord!`
```

### ตัวอย่าง

```text
ใช้คำสั่ง `!help` เพื่อดูคำสั่งทั้งหมด
```

### คืออะไร

เหมาะสำหรับแสดงคำสั่ง ชื่อไฟล์ ชื่อตัวแปร หรือโค้ดสั้น ๆ ที่อยู่ภายในประโยค

---

## 🧑‍💻 8. Code Block หลายบรรทัด

หากต้องการสร้าง Code Block หลายบรรทัด ให้ใช้ Backtick 3 ตัวคร่อมข้อความ

### ไวยากรณ์

````text
```
โค้ดบรรทัดที่ 1
โค้ดบรรทัดที่ 2
โค้ดบรรทัดที่ 3
```
````

### ตัวอย่าง

````text
```
Hello Discord!
This is a code block.
```
````

## 🎨 9. Syntax Highlighting

สามารถระบุชื่อภาษาหลัง Backtick 3 ตัว เพื่อให้ Code Block ใช้ Syntax Highlighting ตามภาษาที่ระบุได้

### JavaScript

````text
```javascript
console.log("Hello Discord!");
```
````

### Python

````text
```python
print("Hello Discord!")
```
````

### JSON

````text
```json
{
  "name": "C2Z Bot",
  "status": "online"
}
```
````

### HTML

````text
```html
<h1>Hello Discord!</h1>
```
````

> **หมายเหตุ:** Discord ระบุว่าการใช้ชื่อภาษาในการทำ Syntax Highlighting สามารถใช้กับ Code Block หลายบรรทัดได้

## 💬 10. Blockquote

ใช้เครื่องหมาย `>` ที่จุดเริ่มต้นของบรรทัดเพื่อสร้าง Blockquote

### Blockquote บรรทัดเดียว

```text
> นี่คือข้อความอ้างอิง
```

ผลลัพธ์:

> นี่คือข้อความอ้างอิง

### ตัวอย่าง

```text
> กรุณาอ่านประกาศนี้ก่อนใช้งานเซิร์ฟเวอร์
```

### คืออะไร

เหมาะสำหรับ:

- คำพูด
- หมายเหตุ
- ประกาศ
- ข้อความที่ต้องการเน้น

> **หมายเหตุ:** ต้องมีช่องว่างระหว่าง `>` กับข้อความ เช่น `> ข้อความ`

---

## 💬 11. Blockquote หลายบรรทัด

หากต้องการสร้าง Blockquote หลายบรรทัด ให้ใช้ `>>>` ก่อนข้อความบรรทัดแรก

### ไวยากรณ์

```text
>>> ข้อความบรรทัดแรก
ข้อความบรรทัดที่สอง
ข้อความบรรทัดที่สาม
```

### ตัวอย่าง

```text
>>> เซิร์ฟเวอร์จะปิดปรับปรุงคืนนี้เวลา 22:00 น.
ผู้ใช้จะไม่สามารถเข้าถึงเซิร์ฟเวอร์ได้ชั่วคราว
ระบบจะกลับมาเปิดให้บริการหลังจากการอัปเดตเสร็จสิ้น
```

### คืออะไร

เหมาะสำหรับข้อความอ้างอิงหรือประกาศที่มีหลายบรรทัด โดยไม่ต้องใส่ `>` ทุกบรรทัด

## 🧩 12. การใช้ Markdown หลายรูปแบบร่วมกัน

สามารถนำ Markdown หลายรูปแบบมาใช้ร่วมกันได้

### ตัวอย่างที่ 1

```text
__**ประกาศสำคัญ**__
```

### ตัวอย่างที่ 2

```text
> **ประกาศ**
>
> เซิร์ฟเวอร์จะปิดเวลา `22:00 น.`
```

### ตัวอย่างที่ 3

```text
## 🚀 Server Update

**ระบบกำลังได้รับการอัปเดต**

- ระบบจะปิดเวลา `22:00 น.`
- ใช้เวลาประมาณ `30 นาที`
- กรุณารอจนกว่าการอัปเดตจะเสร็จสิ้น

||อาจมีการหยุดให้บริการนานกว่าที่คาดไว้||
```

การผสม Markdown หลายรูปแบบช่วยให้ข้อความประกาศหรือคู่มือใน Discord อ่านง่ายและเป็นระเบียบมากขึ้น

## 📌 13. ตารางสรุป Markdown

| รูปแบบ | ไวยากรณ์ | คืออะไร |
| :--- | :--- | :--- |
| ตัวเอียง | `*ข้อความ*` | ทำให้ข้อความเอียง |
| ตัวเอียง | `_ข้อความ_` | ทำให้ข้อความเอียง |
| ตัวหนา | `**ข้อความ**` | ทำให้ข้อความหนา |
| ตัวหนา + ตัวเอียง | `***ข้อความ***` | ทำให้ข้อความหนาและเอียง |
| ขีดเส้นใต้ | `__ข้อความ__` | ขีดเส้นใต้ข้อความ |
| ขีดทับ | `~~ข้อความ~~` | ขีดเส้นทับข้อความ |
| หัวข้อใหญ่ | `# หัวข้อ` | สร้างหัวข้อระดับ 1 |
| หัวข้อกลาง | `## หัวข้อ` | สร้างหัวข้อระดับ 2 |
| หัวข้อเล็ก | `### หัวข้อ` | สร้างหัวข้อระดับ 3 |
| Subtext | `-# ข้อความ` | สร้างข้อความย่อย |
| Spoiler | `\|\|ข้อความ\|\|` | ซ่อนข้อความ |
| ลิงก์ | `[ข้อความ](URL)` | สร้างลิงก์ |
| รายการ | `- รายการ` | สร้างรายการ |
| Inline Code | `` `code` `` | แสดงโค้ดสั้น |
| Code Block | `` ``` `` | แสดงโค้ดหลายบรรทัด |
| Blockquote | `> ข้อความ` | สร้างข้อความอ้างอิง |
| Blockquote หลายบรรทัด | `>>> ข้อความ` | สร้างข้อความอ้างอิงหลายบรรทัด |

## 💡 14. ตัวอย่างข้อความจริง

ตัวอย่างการนำหลายรูปแบบมาใช้ร่วมกัน:

````text
# 🚀 Server Update

**ประกาศจากทีมงาน**

- เซิร์ฟเวอร์จะปิดปรับปรุงเวลา `22:00 น.`
- คาดว่าจะใช้เวลาประมาณ `30 นาที`
- กรุณารอจนกว่าระบบจะเปิดให้บริการอีกครั้ง

> ขณะทำการอัปเดต ผู้ใช้จะไม่สามารถเข้าใช้งานเซิร์ฟเวอร์ได้

-# อัปเดตล่าสุด: 21 สิงหาคม 2026

||อาจมีการเปลี่ยนแปลงระยะเวลาการอัปเดต||
````

## 📚 15. สรุป

รูปแบบ Markdown หลักที่ควรจำสำหรับ Discord มีดังนี้:

```text
*ตัวเอียง*

**ตัวหนา**

***ตัวหนา + ตัวเอียง***

__ขีดเส้นใต้__

~~ขีดทับ~~

# หัวข้อ
## หัวข้อรอง
### หัวข้อย่อย

- รายการ
  - รายการย่อย

-# ข้อความย่อย

[ข้อความ](https://example.com)

||สปอยล์||

> Blockquote

>>> Blockquote หลายบรรทัด

`Inline Code`
```

สำหรับ Code Block:

````text
```javascript
console.log("Hello Discord!");
```
````

เพียงจำรูปแบบเหล่านี้ ก็สามารถจัดข้อความใน Discord ให้เป็นระเบียบและอ่านง่ายขึ้นได้มากครับ
