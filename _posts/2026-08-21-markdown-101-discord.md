Discord รองรับ Markdown สำหรับจัดรูปแบบข้อความ ทำให้เราสามารถทำให้ข้อความอ่านง่ายและเน้นส่วนสำคัญได้โดยไม่ต้องใช้ปุ่มจัดรูปแบบเพิ่มเติม

โพสต์นี้รวบรวมคำสั่ง Markdown ที่ใช้บ่อยใน Discord พร้อมตัวอย่างการใช้งาน

---

## ✏️ ตัวหนา

ใช้เครื่องหมาย `**` คร่อมข้อความ

    **ข้อความตัวหนา**

ผลลัพธ์:

**ข้อความตัวหนา**

เหมาะสำหรับใช้เน้นข้อความสำคัญ เช่น

    **ประกาศสำคัญ**

---

## *ตัวเอียง*

ใช้เครื่องหมาย `*` คร่อมข้อความ

    *ข้อความตัวเอียง*

ผลลัพธ์:

*ข้อความตัวเอียง*

---

## ~~ขีดฆ่า~~

ใช้เครื่องหมาย `~~` คร่อมข้อความ

    ~~ข้อความที่ถูกขีดฆ่า~~

ผลลัพธ์:

~~ข้อความที่ถูกขีดฆ่า~~

---

## ***ตัวหนา + ตัวเอียง***

สามารถใช้ Markdown หลายรูปแบบพร้อมกันได้

    ***ข้อความตัวหนาและตัวเอียง***

ผลลัพธ์:

***ข้อความตัวหนาและตัวเอียง***

---

## __ขีดเส้นใต้__

Discord รองรับการขีดเส้นใต้ด้วย `_` สองตัว

    __ข้อความขีดเส้นใต้__

ผลลัพธ์:

__ข้อความขีดเส้นใต้__

สามารถใช้ร่วมกับตัวหนาได้:

    __**ข้อความตัวหนาและขีดเส้นใต้**__

---

## 🔗 ลิงก์

Discord สามารถสร้างลิงก์แบบ Markdown ได้

    [C2Z](https://c2z.top)

อย่างไรก็ตาม Discord อาจแสดง URL เป็นลิงก์ตามรูปแบบที่กำหนดโดยระบบ

---

## 💻 Code

ใช้เครื่องหมาย Backtick หนึ่งตัว `` ` ``

    `ข้อความหรือคำสั่ง`

ผลลัพธ์:

`ข้อความหรือคำสั่ง`

เหมาะสำหรับชื่อคำสั่ง เช่น:

    `!help`

    `npm install`

    `Ctrl + C`

---

## 💻 Code Block

ใช้ Backtick สามตัวเพื่อสร้างกล่องโค้ด

    ```
    ข้อความหลายบรรทัด
    ```

ตัวอย่าง:

    ```
    สวัสดีครับ
    นี่คือข้อความหลายบรรทัด
    ```

เหมาะสำหรับแสดงข้อความหรือโค้ดที่มีหลายบรรทัด

---

## 🎨 Code Block พร้อมกำหนดภาษา

สามารถระบุภาษาหลัง Backtick สามตัวได้

ตัวอย่าง:

    ```js
    console.log("Hello Discord!");
    ```

หรือ:

    ```html
    <h1>Hello</h1>
    ```

หรือ:

    ```css
    body {
        background: #111;
    }
    ```

Discord จะใช้ Syntax Highlighting เพื่อช่วยให้โค้ดอ่านง่ายขึ้น

---

## 💬 Blockquote

ใช้เครื่องหมาย `>`

    > ข้อความที่ต้องการเน้น

ผลลัพธ์:

> ข้อความที่ต้องการเน้น

สามารถใช้หลายบรรทัดได้:

    > บรรทัดแรก
    > บรรทัดที่สอง
    > บรรทัดที่สาม

---

## 💬 Multi-line Blockquote

ใช้ `>>>` เพื่อทำ Blockquote หลายบรรทัด

    >>>
    ข้อความบรรทัดแรก
    ข้อความบรรทัดที่สอง
    ข้อความบรรทัดที่สาม
    ```

เหมาะสำหรับการยกข้อความยาว ๆ หรือข้อความจากสมาชิกคนอื่น

---

## 📋 รายการแบบจุด

ใช้ `-` หรือ `*`

    - รายการที่ 1
    - รายการที่ 2
    - รายการที่ 3

ผลลัพธ์:

- รายการที่ 1
- รายการที่ 2
- รายการที่ 3

---

## 🔢 รายการแบบตัวเลข

ใช้ตัวเลขตามด้วยจุด

    1. ขั้นตอนที่ 1
    2. ขั้นตอนที่ 2
    3. ขั้นตอนที่ 3

ผลลัพธ์:

1. ขั้นตอนที่ 1
2. ขั้นตอนที่ 2
3. ขั้นตอนที่ 3

---

## 🧩 การรวมหลายรูปแบบ

Markdown สามารถนำหลายคำสั่งมาใช้ร่วมกันได้

ตัวอย่าง:

    **ประกาศสำคัญ**

    > กรุณาอ่านรายละเอียดก่อนดำเนินการ

    1. อ่านข้อความ
    2. ทำตามขั้นตอน
    3. หากมีปัญหาให้ติดต่อทีมงาน

---

## 📌 ตัวอย่างข้อความประกาศ

สามารถนำ Markdown มาจัดข้อความประกาศใน Discord ได้ เช่น

    **📢 ประกาศสำคัญ**

    > เซิร์ฟเวอร์จะปิดปรับปรุงชั่วคราว

    **วันเวลา:** 21 สิงหาคม 2026
    **เวลา:** 23:00 น.

    กรุณาเตรียมตัวออกจากเซิร์ฟเวอร์ก่อนถึงเวลาปิดปรับปรุง

    `ระยะเวลาที่คาดว่าจะใช้: 30 นาที`

---

## 📖 Markdown ที่ใช้บ่อย

| รูปแบบ | คำสั่ง | ผลลัพธ์ |
| --- | --- | --- |
| ตัวหนา | `**ข้อความ**` | **ข้อความ** |
| ตัวเอียง | `*ข้อความ*` | *ข้อความ* |
| ขีดฆ่า | `~~ข้อความ~~` | ~~ข้อความ~~ |
| ขีดเส้นใต้ | `__ข้อความ__` | __ข้อความ__ |
| ตัวหนา + ตัวเอียง | `***ข้อความ***` | ***ข้อความ*** |
| Code | `` `ข้อความ` `` | `ข้อความ` |
| Blockquote | `> ข้อความ` | > ข้อความ |
| รายการ | `- รายการ` | - รายการ |
| ตัวเลข | `1. รายการ` | 1. รายการ |

---

## 🧠 จำง่าย ๆ

ถ้าต้องการใช้งาน Markdown ใน Discord แบบพื้นฐาน จำแค่นี้ก็เพียงพอ:

    **ตัวหนา**

    *ตัวเอียง*

    __ขีดเส้นใต้__

    ~~ขีดฆ่า~~

    `Code`

    ```
    Code Block
    ```

    > Blockquote

    - รายการ

    1. รายการตัวเลข

---

## 💡 สรุป

Markdown ช่วยให้ข้อความใน Discord อ่านง่ายและดูเป็นระเบียบมากขึ้น โดยเฉพาะการเขียนประกาศ คู่มือ กฎของเซิร์ฟเวอร์ หรือข้อความที่มีข้อมูลหลายส่วน

ไม่จำเป็นต้องจำทุกคำสั่งในครั้งเดียว แค่เริ่มจาก **ตัวหนา**, *ตัวเอียง*, `Code`, Blockquote และรายการ ก็สามารถใช้งานได้เกือบทุกสถานการณ์แล้ว

> **Markdown ไม่ได้มีไว้แค่ทำให้ข้อความสวยขึ้น แต่ช่วยให้คนอ่านเข้าใจข้อมูลได้ง่ายขึ้นด้วย**
